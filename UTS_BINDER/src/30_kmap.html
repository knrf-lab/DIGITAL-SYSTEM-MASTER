3Aturan grouping (SOP = group angka 1)

  1. Ukuran grup 1, 2, 4, 8, 16 (2ⁿ). Tidak boleh 3, 5, 6.
  2. Bentuk persegi / persegi panjang, horizontal & vertikal saja. Tidak boleh diagonal atau bentuk L.
  3. Grup sebesar mungkin (makin besar → makin sedikit literal).
  4. Jumlah grup sesedikit mungkin, tapi semua 1 harus tertutup.
  5. Grup boleh overlap.
  6. Map melingkar: kiri ↔ kanan, atas ↔ bawah, 4 pojok = 1 grup.
  7. Jangan buat grup yang semua selnya sudah ditutup grup lain.

4Cara membaca grup

Lihat tiap variabel di seluruh sel grup: berubah (0 dan 1) → buang · selalu 1 → tulis \(a\) · selalu 0 → tulis \(\bar a\). Untuk POS (grup angka 0) dibalik: selalu 0 → \(a\), selalu 1 → \(\bar a\), dan tiap grup jadi sum term (OR).

5Don't care (X)

Kombinasi input yang tidak mungkin terjadi (mis. BCD 1010–1111) atau outputnya tidak penting. Boleh dianggap 1 kalau membuat grup lebih besar, boleh diabaikan kalau tidak. X tidak wajib ditutup grup. Contoh papan tulis: m5, m6, m7 = X.

{{inc:dc_x1}}{{inc:dc_x0}}

Dengan X: \(y = a + \bar b c + b\bar c\) (3 term pendek). Tanpa X: \(y=\bar a\bar b c+\bar a b\bar c+a\bar b\bar c\) (3 term panjang). Pakai X kalau soal bilang “tidak mungkin terjadi”.

6K-map 5 variabel

Buat 2 map 4×4: satu untuk a = 0 (m0–m15), satu untuk a = 1 (m16–m31), isi dengan b c d e. Sel di posisi yang sama di kedua map = bersebelahan → bisa digabung (a hilang). Grup yang hanya ada di satu map ditulis dengan \(\bar a\) atau \(a\).

{{inc:k5_ex}}

PR5 Q28: Σm(4–7, 12–15, 20–23). Map a = 0: octet “c” (m4–7, m12–15), ada di map ini saja → \(\bar a c\). Map a = 1: quad \(\bar b c\) (m20–23); posisi yang sama di map a = 0 (m4–7) juga 1 → a hilang → \(\bar b c\). Hasil: \(y=\bar a c + \bar b c\).

7Menggambar rangkaian dari SOP

  1. Tulis semua input sebagai garis vertikal. Butuh \(\bar a\)? Tambah NOT, buat garis baru.
  2. Setiap product term = 1 gerbang AND (titik ● = sambungan).
  3. Semua output AND masuk ke 1 gerbang OR → y.
  4. Term 1 literal tidak perlu AND, langsung ke OR.

Contoh papan tulis: \(y = cd + \bar a b d + \bar a\bar b c\)

NAND–NAND: SOP bisa dibuat hanya dengan NAND: ganti semua AND dan OR dengan NAND (bubble ganda saling hapus). \(y = ab+ac+bc = \overline{\overline{ab}\cdot\overline{ac}\cdot\overline{bc}}\). POS → NOR–NOR.
