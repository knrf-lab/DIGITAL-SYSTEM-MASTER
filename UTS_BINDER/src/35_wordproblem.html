Case 1 · AMR navigation interlock

A = LiDAR obstacle, B = track lost, C = bumper ditekan. Y = 1 → divert. C = 1: trip hanya jika tepat satu dari A, B aktif → Y = A⊕B (m3, m5). C = 0: trip jika A = 0, atau A = 1 & B = 0, kecuali A = B = C = 0 → m2, m4 (m0 dikecualikan, m6 = 0). Failsafe A = 0, B = 1, C = 0 → m2 (sudah termasuk).

Case 2 · Avionics data bus arbiter

A = watchdog fault, B = CRC error, C = voltage ripple. Rule 1: B = 1 & C = 1 → Y = 1 (A bebas) → m3, m7. Rule 2: C = 0 & A ≠ B → m2, m4. Rule 3: A = B = 0 & C = 1 → Y = 0 (m1). Baris lain tidak trip.

Case 3 · Battery thermal runaway isolation

A = overcurrent, B = thermal gradient, C = off-gas. A = 1: fire iff C = 1 → m5, m7 (m4, m6 = 0). A = 0 & C = 1: fire jika B = 0 → m1 (m3 = 0). C = 0: fire iff A = 0 (B bebas) → m0, m2.
