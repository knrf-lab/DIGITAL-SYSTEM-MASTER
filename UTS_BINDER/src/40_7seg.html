Seven-segment (LED) decoder: tabel lengkap · soal 24

1BCD → 7-segment, common cathode (1 = nyala)

{{inc:seg_table}}

Input A B C D: A = MSB (8), D = LSB (1) → baris = nomor minterm m0–m15. Angka 6 pakai “ekor” (segmen a nyala), angka 9 pakai segmen d. Baris 10–15 bukan BCD valid → don't care (X) saat merancang.

2Nama segmen

{{svg:seg_diagram}}

Searah jarum jam dari atas: a atas, b kanan-atas, c kanan-bawah, d bawah, e kiri-bawah, f kiri-atas, g tengah (+ dp, titik desimal).

3Common cathode vs common anode

Common cathode (CC)Common anode (CA)
Pin bersamakatoda → GNDanoda → VCC
Segmen nyala jikainput 1 (HIGH)input 0 (LOW)
Driveractive-HIGH (74LS48)active-LOW (74LS47)
Tabeltabel di kiribalik semua bit a–g

CA: persamaannya \(\bar a, \bar b, …\) dari tabel CC. Cara cepat: group angka 0 di K-map CC → itu SOP untuk output CA (active-LOW).

4Langkah merancang decoder

  1. Truth table: 4 input BCD → 7 output (a–g). Baris 10–15 = X.
  2. 1 K-map per segmen (7 K-map), isi 1/0 dari kolom segmennya, X di m10–m15.
  3. Group angka 1, pakai X kalau membesarkan grup → SOP tiap segmen.
  4. Segmen yang OFF-nya sedikit (b, c) → lebih cepat group angka 0 (POS).
  5. Gambar rangkaian per segmen: AND–OR (atau NAND–NAND).
Nama bertabrakan: di papan tulis input ditulis “d c b a” dan segmen juga a–g. Pakai A B C D (huruf besar) untuk input, a–g (kecil) untuk segmen, dan tulis konvensinya di jawaban (“A = MSB”).

Segmen c lewat angka 0 (POS)

{{inc:seg_c_pos}}

Segmen c hanya OFF di angka 2 (0010). Group 0 itu bersama X m10 → \(\bar c = \bar B C\bar D\) → De Morgan: \(c = \overline{\bar B C \bar D} = B + \bar C + D\). Sama dengan hasil SOP.
Maxterm murni (tanpa X): \(c = (A + B + \bar C + D)\).

Papan tulis menulis segmen c = (a + b̄ + c + d). Itu salah: angka 2 = 0010, jadi maxterm-nya \((A+B+\bar C+D)\). Prof sendiri bilang sempat keliru di kelas.

Variasi soal yang mungkin

  • Common anode → tulis tabel terbalik (0 = nyala), atau tulis \(\bar a = …\) dari grup angka 0.
  • Hanya 0–7 (3 bit A B C) → 8 baris, K-map 3 variabel, tanpa don't care (lihat mock soal 2 {{p:SM}}).
  • Heksadesimal 0–F → 16 baris semua terpakai, tanpa X; huruf A b C d E F:
{{inc:hex_icons}}
  • “Hanya segmen tertentu” → kerjakan hanya K-map segmen yang diminta.
  • Tanpa ekor (74LS47 asli: 6 tanpa a, 9 tanpa d) → ubah 2 sel itu, hasil a dan d berubah. Ikuti tabel yang diberikan soal.
  • LED biasa (bukan 7-seg), mis. “LED nyala jika …” → sama dengan soal cerita: 1 LED = 1 output = 1 K-map.
