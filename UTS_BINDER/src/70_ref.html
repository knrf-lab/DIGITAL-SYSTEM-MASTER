Konversi bilangan (PR Pert. 2)

  • Desimal → biner: bagi 2 berulang, baca sisa dari bawah ke atas.
  • Biner → oktal: kelompok 3 bit dari kanan. Biner → heksa: kelompok 4 bit.
  • Ke desimal: kalikan tiap digit dengan bobotnya (2ⁿ, 8ⁿ, 16ⁿ).

Penjumlahan & 2's complement

0+0 = 0 · 0+1 = 1 · 1+1 = 10 (tulis 0, carry 1) · 1+1+1 = 11.

A − B: (1) 1's complement B = balik semua bit · (2) +1 = 2's complement · (3) A + 2's(B) · (4) ada carry keluar → buang, hasil positif. Tidak ada carry → hasil negatif (ambil 2's complement-nya lagi, beri tanda −).

BCD & Gray

  • BCD (8421): tiap digit desimal → 4 bit. 1010–1111 tidak dipakai. 859 = 1000 0101 1001.
  • Gray code: angka berurutan hanya beda 1 bit (00, 01, 11, 10, …). Ini sebabnya header K-map memakai Gray.

Comparator, adder, decoder (1 baris)

  • Sama 1-bit: XNOR. Sama 4-bit: AND dari 4 XNOR.
  • Half adder: S = a⊕b, C = ab. Full adder: S = a⊕b⊕cin, Cout = ab + cin(a⊕b).
  • Decoder: 1 output aktif untuk tiap kombinasi input (n → 2ⁿ). 74LS47 = BCD → 7-seg, active-LOW (common anode).

PLD / VHDL (kalau keluar)

  • PLD = IC berisi banyak gerbang yang dikonfigurasi user lewat software. SPLD (PAL: AND array programmable + OR tetap, OTP; GAL: bisa diprogram ulang) · CPLD (beberapa SPLD/LAB + interkoneksi PIA) · FPGA (banyak CLB berisi LUT + flip-flop).
  • Design flow: design entry (schematic/HDL) → functional simulation → synthesis (netlist) → implementation (fit/place & route) → timing simulation → device programming.
  • VHDL: entity = port input/output; architecture = perilaku/struktur. Signal <=, variable :=. component + port map = menyambung modul (seperti lab Ch. 5 & 7).
