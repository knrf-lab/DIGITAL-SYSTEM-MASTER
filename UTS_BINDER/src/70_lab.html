1Rangkaian kombinasional

Analisis rangkaian: tulis ekspresi di output tiap gerbang dari input ke output → gabung → sederhanakan → truth table. Pulse waveform: kerjakan interval demi interval. AND–OR = SOP langsung; AOI (AND-OR-Invert) = \(\overline{ab+cd}\).

  • Parallel adder: n full adder berantai. Ripple carry: tiap tahap menunggu carry sebelumnya (lambat). Look-ahead: carry dihitung langsung; generate \(C_g=ab\), propagate \(C_p=a+b\), \(C_{out}=C_g+C_pC_{in}\). 74LS283 = 4-bit adder look-ahead.
  • Comparator: sama 1-bit = XNOR; 4-bit = AND dari 4 XNOR. Magnitude comparator (74LS85): A>B, A=B, A<B, cek dari MSB; cascade lewat input A=B.
  • Decoder: mendeteksi 1 kombinasi input (n → 2ⁿ output). 74LS138 = 3-to-8 (3 enable), 74HC154 = 4-to-16, 74HC42 = BCD-to-decimal, 74LS47 = BCD-to-7-seg active-LOW.

3Konsep modeling

  • Tujuan: simulasi & sintesis. Representasi: structural, behavioral, physical. Abstraksi: functional → RTL → logic → circuit → physical.
  • Simulation = memodelkan rangkaian untuk meniru perilakunya. Synthesis = membangkitkan hardware dari model; inputnya model VHDL + constraint + target primitive; ia meng-infer komponen & optimasi ukuran/kecepatan.
  • Signal: punya riwayat nilai terhadap waktu; berubah bersamaan (concurrent). Event = perubahan nilai pada suatu waktu; output tertunda propagation delay.
  • Inertial delay (default): perubahan input harus bertahan cukup lama, glitch pendek diabaikan (OUT1 <= IN1 after 8 ns;). Transport delay: delay kabel, semua pulsa lewat (sum <= transport s1 after 4 ns;).
  • Testbench: entity kosong (tanpa port) berisi DUT + stimulus; error/warning ke console atau log.

4VHDL essentials

entity HALFADDER is
  port( A, B       : in  std_logic;
        SUM, CARRY : out std_logic );
end HALFADDER;
architecture RTL of HALFADDER is
begin
  SUM   <= A xor B;   -- concurrent
  CARRY <= A and B;
end RTL;

Entity = port input/output. Architecture = hubungan/perilaku. Case-insensitive · komentar -- · akhir statement ; · signal <= · variable := · identifier mulai huruf, tidak berakhir _.
